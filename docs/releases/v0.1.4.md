# DVAAC v0.1.4

Signed patch release for the Damn Vulnerable Agent Asset Corpus. This release supersedes `v0.1.3` without rewriting public history.

## Highlights

- Pins DVAAC to AAC `v0.2-candidate.7`.
- Updates the AAC verifier commit to `689198d9c249a966a0abab6415ae8668efb512d9`.
- Includes the external validation guide, validation ledger, structured issue forms, submitted-scorecard validator, CodeQL workflow, Dependabot coverage, dependency-floor updates, and protected-branch policy documentation now present on `main`.
- Keeps fixture semantics unchanged from `v0.1.3`; this is a review-tooling, supply-chain, and compatibility-pin patch release.

## Known Limits

- Demo-key signatures prove verifier plumbing and reproducibility, not author identity.
- DVAAC is a compact conformance corpus, not a statistical safety benchmark.
- No accepted third-party scanner submissions are recorded yet.
